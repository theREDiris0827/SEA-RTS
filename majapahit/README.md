# The Treasurer's Gate (Majapahit demo)

Singapura, 1398, from the attacker's side. Command the Majapahit fleet from the Jong Raya flagship: launch boats of troops, land on Batam island and build a Lumbung, win over the Orang Laut, send a messenger to the king's treasurer (or break a gate by force), and raise the red and white banner over Bukit Larangan before Ayutthaya takes the city first. About 15 to 20 minutes.

Play: https://therediris0827.github.io/SEA-RTS/majapahit/  (practice starts: `#siege`, `#palace`)

Built from the main game by `majapahit-demo/src/build.py` in the project files; this folder holds only the built page.
