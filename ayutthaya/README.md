# The Fall of Angkor (Ayutthaya demo)

A standalone demo of SEA Kingdoms: Ayutthaya's siege of Yasodharapura (Angkor), 1431.

Play: https://therediris0827.github.io/SEA-RTS/ayutthaya/

- Burn the timber town outside the moat with fire arrows and take the outworks.
- Break a face gate with Chang Suek war elephants (fire does not touch laterite).
- Bring King Borommarachathirat II into the royal palace court and raise his banner.

Practice links: `#gates` and `#palace` at the end of the URL start later in the siege.

Built from the main game by `ayutthaya-demo/src/build.py` in the project files; this folder holds only the built page.
